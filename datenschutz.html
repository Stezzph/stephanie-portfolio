Besuch der Website

Beim Besuch dieser Website können technische Daten verarbeitet werden, zum Beispiel IP-Adresse, Browser, Gerät, Betriebssystem, Besuchszeit und aufgerufene Seiten.

Diese Daten werden verwendet, damit die Website korrekt angezeigt wird, technisch funktioniert und sicher betrieben werden kann.

Kontaktformular und E-Mail

Das Kontaktformular speichert oder versendet selbst keine Daten. Beim Absenden öffnet sich dein eigenes E-Mail-Programm mit einer vorbereiteten Nachricht (Name, E-Mail-Adresse und Nachricht). Erst wenn du diese E-Mail selbst abschickst, erhalte ich deine Angaben.

Deine Angaben verwende ich ausschliesslich, um deine Anfrage zu beantworten. Für den E-Mail-Versand gelten zusätzlich die Datenschutzbestimmungen deines E-Mail-Anbieters.

Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt, einen Dienst der GitHub Inc. (USA). Beim Aufruf der Website verarbeitet GitHub technisch notwendige Daten wie IP-Adresse, Zeitpunkt des Aufrufs und Browser-Informationen, um die Website auszuliefern und vor Missbrauch zu schützen. Dabei können Daten in die USA übermittelt werden.

Weitere Informationen findest du in der Datenschutzerklärung von GitHub.

Ich setze keine Cookies, keine Analyse- oder Tracking-Tools und keine externen Schriftarten ein. Schriften und Bilder werden direkt von dieser Website geladen.

Externe Inhalte und Social Media

Auf dieser Website können Links oder eingebettete Inhalte von Plattformen wie Instagram, TikTok, LinkedIn, YouTube, blue News, SwissSkills oder anderen externen Seiten enthalten sein.

Auf der Seite «Social Media Projekte» sind Videos von TikTok und Instagram eingebettet. Beim Aufruf dieser Seite werden Inhalte direkt von den Servern von TikTok bzw. Instagram (Meta) geladen. Dabei können diese Anbieter Daten wie deine IP-Adresse erfassen und Cookies setzen.

Wenn du solche Inhalte anklickst oder externe Seiten öffnest, gelten die Datenschutzbestimmungen der jeweiligen Anbieter.
